# Embryo Network Monitor

Embryo Network Monitor is Embryo-Zero's fork of [librenms](https://github.com/librenms/librenms) (d760497a, commit d760497a). It does network device monitoring (SNMP).

- Our changes live on the `embryo` branch. The original license files (LICENSE.txt) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
